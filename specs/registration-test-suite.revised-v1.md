# Specification

## Goal

To create a simple user registration feature where users can register by providing an email address and a password.

## Context

None

## Functional Requirements

### FR-001

**Source:** USER

Users can provide an email address during registration.
- **Details:** The email field should accept standard email formats (e.g., `example@domain.com`).

### FR-002

**Source:** USER

Users can provide a password during registration.
- **Details:** The password field should allow users to input passwords without displaying them in plain text.

## Non-Functional Requirements

None

## Acceptance Criteria

### AC-001

**Source:** USER

A user can register using an email address and a password.
